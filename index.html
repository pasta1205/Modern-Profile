Secure Website Hosting with Private RDS Access via AWS Client VPN

Project Overview:

This project demonstrates a fully private cloud infrastructure on AWS where a static website is hosted on an EC2 instance in a public subnet, while a PostgreSQL database is deployed inside private subnets and accessed securely using AWS Client VPN. DNS management is done using Route 53, and access control is tightly restricted using Security Groups and IAM roles.

📦 Key Components:
  • Custom VPC with 1 Public Subnet + 2 Private Subnets (ap-south-1b & ap-south-1c)
  • Amazon EC2 (Ubuntu) in Public Subnet hosting website
  • Amazon RDS (PostgreSQL) deployed in Private Subnet
  • Client VPN Endpoint using certificate-based authentication (TCP)
  • Domain routed via Route 53: parthasarathisamanta.pastaworld.in (Temporary site for project only!! Visit: profile.pastaworld.in)
  • Internet Gateway attached to VPC for EC2 access
🔐 Security & Access Setup:
  • RDS made private – accessible only via VPN
  • Client VPN authorized with proper CIDR (11.0.0.0/16)
  • Security Groups configured for least privilege (Port 5432 only from VPN)
  • pgAdmin used from local machine to test DB connection

Custom VPC with EC2, RDS, VPN, and Route 53 setup

🛠️ Tools & Services Used:
  • Amazon EC2, Amazon RDS (PostgreSQL), Client VPN Endpoint
  • VPC, Subnet Groups, Route Tables, Internet Gateway
  • Route 53, Security Groups, OpenVPN-GUI
  • pgAdmin, PowerShell for connectivity testing

Static Website Hosting on AWS S3 with CloudFront & Route 53

Project Overview:

This project demonstrates how to host a fully static and responsive HTML portfolio website on Amazon S3 with secure and performant global delivery using Amazon CloudFront. Custom domain configuration is done with Route 53, including subdomain redirection and HTTPS support via ACM.

📦 Key Components:
  • Amazon S3 for static site hosting
  • Amazon CloudFront distribution for CDN delivery
  • Custom domain: profile.pastaworld.in
  • ACM-issued SSL certificate for HTTPS
  • Route 53 for DNS routing and domain redirection
🚀 Features & Implementation:
  • Mobile-friendly HTML/CSS portfolio design
  • Clean URL access through CloudFront
  • Invalidation done after content updates for cache refresh
  • Email button redirects to Gmail compose window with prefilled recipient
